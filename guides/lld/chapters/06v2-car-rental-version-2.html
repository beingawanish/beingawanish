Key design decisions.

  1. Compose version 1; do not subclass RentalService. A subclass would inherit the private _lock, _factory and _reservations, and the first override would couple you to them. RentalDesk holds a RentalService and calls only its public methods. If version 1 rewrites its internals tomorrow, the desk does not notice.
  2. New facts about a reservation live in a Trip, keyed by the same id. Branches, the locked price, the late fee and the stage all belong to version 2. Adding them to Reservation would mean editing version 1. A side record keyed by reservation_id adds them without a single edit.
  3. Where the car is, and what it is doing, is a separate fact from who has booked it. A reservation is a date window. The lifecycle state is the car right now: on the lot, on rent, in the workshop, on a charger. Mixing the two is how "the car is booked but also in for repair" bugs happen. They get separate classes and separate rules.
  4. Money first, then commit. At the end of an inspection the desk settles the payment before it records new damage or moves the car. If the gateway times out, nothing has changed, and a retry re-prices the same report with the same idempotency keys.
  5. Every rule set is a list of small classes. Pricing rules and return rules are both chains. Adding a rule means adding a class and one line in wiring.py. The chain itself never changes.

Step 2 — Configuration, with validation

Goal: put every new number in one frozen dataclass per feature, and make bad numbers fail at startup.

Type car_rental_v2/config.py:

"""Version 2 configuration: every number the follow-ups introduce.

Version 1's RentalConfig is untouched. V2Config sits beside it and holds only
what the follow-ups added. Each section validates itself in __post_init__,
so a bad number fails at startup, not halfway through a quote.
"""
from dataclasses import dataclass, field

from car_rental import VehicleCategory

from .models import DamageKind, LoyaltyTier


def _fraction(value: float, name: str) -> None:
    if not 0.0 <= value < 1.0:
        raise ValueError(f"{name} must be in [0, 1), got {value}")


@dataclass(frozen=True)
class PricingRulesConfig:
    weekend_days: frozenset[int] = frozenset({5, 6})   # date.weekday(): Sat, Sun
    weekend_multiplier: float = 1.2
    # (utilisation at least, multiplier), highest threshold first.
    surge_tiers: tuple[tuple[float, float], ...] = ((0.8, 1.25), (0.5, 1.10))
    long_rental_min_days: int = 7
    long_rental_discount: float = 0.10
    loyalty_discounts: dict[LoyaltyTier, float] = field(default_factory=lambda: {
        LoyaltyTier.NONE: 0.0,
        LoyaltyTier.SILVER: 0.05,
        LoyaltyTier.GOLD: 0.10,
    })

    def __post_init__(self) -> None:
        if self.weekend_multiplier < 1.0:
            raise ValueError("weekend_multiplier must be >= 1")
        thresholds = [t for t, _ in self.surge_tiers]
        if thresholds != sorted(thresholds, reverse=True):
            raise ValueError("surge_tiers must be ordered highest threshold first")
        for threshold, multiplier in self.surge_tiers:
            if not 0.0 <= threshold <= 1.0 or multiplier < 1.0:
                raise ValueError(f"bad surge tier ({threshold}, {multiplier})")
        if self.long_rental_min_days < 1:
            raise ValueError("long_rental_min_days must be >= 1")
        _fraction(self.long_rental_discount, "long_rental_discount")
        for tier in LoyaltyTier:
            _fraction(self.loyalty_discounts.get(tier, 0.0), f"loyalty {tier.name}")


@dataclass(frozen=True)
class EvConfig:
    min_pickup_charge_pct: int = 50    # below this the car is not handed out
    min_return_charge_pct: int = 80    # below this the customer pays to recharge
    recharge_fee_per_pct: float = 0.75

    def __post_init__(self) -> None:
        for name in ("min_pickup_charge_pct", "min_return_charge_pct"):
            if not 0 <= getattr(self, name) <= 100:
                raise ValueError(f"{name} must be within 0..100")
        if self.recharge_fee_per_pct < 0:
            raise ValueError("recharge_fee_per_pct must be >= 0")


@dataclass(frozen=True)
class InspectionConfig:
    damage_charges: dict[DamageKind, float] = field(default_factory=lambda: {
        DamageKind.SCRATCH: 150.0,
        DamageKind.DENT: 400.0,
        DamageKind.CRACKED_GLASS: 650.0,
        DamageKind.INTERIOR_STAIN: 120.0,
    })
    needs_repair: frozenset[DamageKind] = frozenset(
        {DamageKind.DENT, DamageKind.CRACKED_GLASS})

    def __post_init__(self) -> None:
        missing = set(DamageKind) - set(self.damage_charges)
        if missing:
            raise ValueError(f"no charge configured for {sorted(k.name for k in missing)}")

Step 4 — The rules and the chain

Goal: type the PricingRule interface, four rules, and RuleChainPricing, which is a version 1 PricingStrategy.

Type car_rental_v2/pricing_rules.py:

"""Dynamic pricing as a chain of rules.

RuleChainPricing *is* a v1 PricingStrategy, so the untouched v1 RentalService
accepts it through its constructor. It starts from the v1 StandardPricing
quote and lets each rule add one line: a surcharge (positive) or a discount
(negative). A new rule is a new class appended to the list.

Order is part of the configuration: surcharges first, then percentage
discounts (which see the surcharged subtotal), then flat fees nobody discounts.
"""
import logging
import threading
from abc import ABC, abstractmethod
from collections.abc import Sequence
from dataclasses import dataclass
from datetime import date, timedelta

from car_rental import (
    FleetRepository,
    PricingStrategy,
    RentalConfig,
    Reservation,
    ReservationRepository,
    StandardPricing,
    Vehicle,
    VehicleCategory,
)

from .config import PricingRulesConfig
from .models import LoyaltyTier, PriceLine, Quote

log = logging.getLogger(__name__)


# -- the data sources the rules need ---------------------------------------

class UtilisationSource(ABC):
    @abstractmethod
    def utilisation(self, category: VehicleCategory, start: date, end: date,
                    exclude_vehicle_id: str) -> float:
        """Share of the category already booked for [start, end), 0.0..1.0."""


class FleetUtilisation(UtilisationSource):
    """Reads the v1 repositories. The car being priced does not count itself."""

    def __init__(self, fleet: FleetRepository, reservations: ReservationRepository):
        self._fleet = fleet
        self._reservations = reservations

    def utilisation(self, category: VehicleCategory, start: date, end: date,
                    exclude_vehicle_id: str) -> float:
        cars = self._fleet.by_category(category)
        if not cars:
            return 0.0
        busy = sum(1 for v in cars
                   if v.vehicle_id != exclude_vehicle_id
                   and self._reservations.has_overlap(v.vehicle_id, start, end))
        return busy / len(cars)


class LoyaltyDirectory(ABC):
    @abstractmethod
    def tier_for(self, customer_name: str) -> LoyaltyTier: ...


class InMemoryLoyalty(LoyaltyDirectory):
    def __init__(self, tiers: dict[str, LoyaltyTier] | None = None):
        self._lock = threading.Lock()   # guards _tiers
        self._tiers = dict(tiers or {})

    def set_tier(self, customer_name: str, tier: LoyaltyTier) -> None:
        with self._lock:
            self._tiers[customer_name] = tier

    def tier_for(self, customer_name: str) -> LoyaltyTier:
        with self._lock:
            return self._tiers.get(customer_name, LoyaltyTier.NONE)


# -- the rules ----------------------------------------------------------------

@dataclass(frozen=True)
class PricingContext:
    vehicle: Vehicle
    reservation: Reservation
    daily_rate: float
    utilisation: float
    tier: LoyaltyTier
    rules: PricingRulesConfig

    @property
    def base(self) -> float:
        """Days x daily rate: the part surcharges scale. Add-ons never surge."""
        return self.reservation.days * self.daily_rate

    def dates(self) -> list[date]:
        start = self.reservation.start_date
        return [start + timedelta(days=i) for i in range(self.reservation.days)]


class PricingRule(ABC):
    @abstractmethod
    def adjust(self, ctx: PricingContext, subtotal: float) -> PriceLine | None:
        """One line to add to the quote, or None when the rule does not apply."""


class WeekendRule(PricingRule):
    def adjust(self, ctx: PricingContext, subtotal: float) -> PriceLine | None:
        weekend = sum(1 for d in ctx.dates() if d.weekday() in ctx.rules.weekend_days)
        if weekend == 0:
            return None
        extra = weekend * ctx.daily_rate * (ctx.rules.weekend_multiplier - 1)
        return PriceLine(f"weekend x{weekend}", round(extra, 2))


class SurgeRule(PricingRule):
    def adjust(self, ctx: PricingContext, subtotal: float) -> PriceLine | None:
        for threshold, multiplier in ctx.rules.surge_tiers:
            if ctx.utilisation >= threshold:
                extra = ctx.base * (multiplier - 1)
                return PriceLine(f"surge ({ctx.utilisation:.0%} booked)",
                                 round(extra, 2))
        return None


class LongRentalDiscount(PricingRule):
    def adjust(self, ctx: PricingContext, subtotal: float) -> PriceLine | None:
        if ctx.reservation.days < ctx.rules.long_rental_min_days:
            return None
        cut = subtotal * ctx.rules.long_rental_discount
        return PriceLine(f"long rental ({ctx.reservation.days} days)", -round(cut, 2))


class LoyaltyDiscount(PricingRule):
    def adjust(self, ctx: PricingContext, subtotal: float) -> PriceLine | None:
        pct = ctx.rules.loyalty_discounts.get(ctx.tier, 0.0)
        if pct == 0.0:
            return None
        return PriceLine(f"loyalty {ctx.tier.name}", -round(subtotal * pct, 2))


# -- the chain ----------------------------------------------------------------

class RuleChainPricing(PricingStrategy):
    def __init__(self, rules: Sequence[PricingRule], rules_config: PricingRulesConfig,
                 utilisation: UtilisationSource, loyalty: LoyaltyDirectory,
                 base: PricingStrategy | None = None):
        self._rules = list(rules)
        self._rules_config = rules_config
        self._utilisation = utilisation
        self._loyalty = loyalty
        self._base = base or StandardPricing()

    def explain(self, vehicle: Vehicle, reservation: Reservation,
                config: RentalConfig) -> Quote:
        standard = self._base.quote(vehicle, reservation, config)
        ctx = PricingContext(
            vehicle=vehicle,
            reservation=reservation,
            daily_rate=config.daily_rates[vehicle.category],
            utilisation=self._utilisation.utilisation(
                vehicle.category, reservation.start_date, reservation.end_date,
                vehicle.vehicle_id),
            tier=self._loyalty.tier_for(reservation.customer_name),
            rules=self._rules_config,
        )
        lines = [PriceLine("standard", standard)]
        subtotal = standard
        for rule in self._rules:
            line = rule.adjust(ctx, subtotal)
            if line is not None and line.amount != 0:
                lines.append(line)
                subtotal = round(subtotal + line.amount, 2)
        log.debug("quote %s: %s", reservation.reservation_id, lines)
        return Quote(tuple(lines))

    # The two methods v1 calls. Same signatures, same meaning: Liskov holds.
    def quote(self, vehicle: Vehicle, reservation: Reservation,
              config: RentalConfig) -> float:
        return self.explain(vehicle, reservation, config).total

    def late_fee(self, late_days: int, config: RentalConfig) -> float:
        return self._base.late_fee(late_days, config)

What to notice. Three things.

First, RuleChainPricing keeps both version 1 method signatures, quote and late_fee, with the same meaning. That is why you can hand it to the untouched RentalService. The checkpoint below does exactly that.

Second, each rule returns one line, not a new total. The chain adds the lines up. So every quote can explain itself: the customer sees "weekend x2: +20.00", not a mystery number.

Third, order is configuration. Percentage discounts see the surcharged subtotal, because they come after the surcharges in the list. Swap them and a gold customer would get 10% off a smaller number. Neither order is wrong; the business picks one, and the list in wiring.py writes it down.

11.5 Feature 2: the EV fleet

The electric car itself was typed in Step 1. What is left is the business rule: an EV must come back charged, and a nearly empty one cannot go out. The pickup check lives in the desk (Step 10). The return charge is a rule of its own.

Step 5 — Return rules, starting with low charge

from abc import ABC, abstractmethod

class ReturnRule(ABC):
    @abstractmethod
    def charges(self, vehicle: Vehicle, report: InspectionReport) -> list[PriceLine]:
        ...


class LowChargeRule(ReturnRule):
    """EVs only: below the return threshold, pay per missing percentage point."""

    def __init__(self, config: EvConfig):
        self._config = config

    def charges(self, vehicle: Vehicle, report: InspectionReport) -> list[PriceLine]:
        if not isinstance(vehicle, ElectricVehicle):
            return []
        if report.charge_pct is None:
            raise ValueError(f"{vehicle.vehicle_id} is electric: report needs charge_pct")

        fee = round(shortfall * self._config.recharge_fee_per_pct, 2)
        return [PriceLine(f"recharge ({report.charge_pct}% < "
                          f"{self._config.min_return_charge_pct}%)", fee)]

Step 6 — The state machine

Goal: type TRANSITIONS, the status repository, and VehicleLifecycle, which refuses any move the table does not list.

Type car_rental_v2/lifecycle.py:

"""The vehicle lifecycle: an explicit state machine.

A Reservation says who has a car for which dates. It says nothing about the
car itself: is it on the lot, in the workshop, on a charger? That is a
separate fact with separate rules, so it gets its own table and its own class.
Every legal move is listed in TRANSITIONS; anything else raises.
"""
import logging
import threading
from abc import ABC, abstractmethod

from car_rental import Clock, VehicleNotFoundError

from .errors import InvalidTransitionError
from .models import Transition, VehicleState, VehicleStatus

log = logging.getLogger(__name__)

S = VehicleState
TRANSITIONS: dict[VehicleState, frozenset[VehicleState]] = {
    S.AVAILABLE: frozenset({S.ON_RENT, S.MAINTENANCE, S.RETIRED}),
    S.ON_RENT: frozenset({S.AWAITING_INSPECTION}),
    S.AWAITING_INSPECTION: frozenset({S.AVAILABLE, S.MAINTENANCE, S.CHARGING}),
    S.MAINTENANCE: frozenset({S.AVAILABLE, S.RETIRED}),
    S.CHARGING: frozenset({S.AVAILABLE, S.MAINTENANCE}),
    S.RETIRED: frozenset(),
}


class StatusRepository(ABC):
    @abstractmethod
    def get(self, vehicle_id: str) -> VehicleStatus | None: ...
    @abstractmethod
    def save(self, status: VehicleStatus) -> None: ...


class InMemoryStatuses(StatusRepository):
    def __init__(self):
        self._lock = threading.Lock()   # guards _statuses
        self._statuses: dict[str, VehicleStatus] = {}

    def get(self, vehicle_id: str) -> VehicleStatus | None:
        with self._lock:
            return self._statuses.get(vehicle_id)

    def save(self, status: VehicleStatus) -> None:
        with self._lock:
            self._statuses[status.vehicle_id] = status


class VehicleLifecycle:
    def __init__(self, statuses: StatusRepository, clock: Clock):
        self._statuses = statuses
        self._clock = clock
        self._lock = threading.RLock()   # makes read-check-write one step

    def register(self, vehicle_id: str, branch_id: str) -> VehicleStatus:
        status = VehicleStatus(vehicle_id, VehicleState.AVAILABLE, branch_id)
        self._statuses.save(status)
        return status

    def status(self, vehicle_id: str) -> VehicleStatus:
        status = self._statuses.get(vehicle_id)
        if status is None:
            raise VehicleNotFoundError(f"no status for vehicle {vehicle_id}")
        return status

    def transition(self, vehicle_id: str, to: VehicleState, reason: str,
                   branch_id: str | None = None) -> VehicleStatus:
        with self._lock:
            status = self.status(vehicle_id)
            if to not in TRANSITIONS[status.state]:
                raise InvalidTransitionError(
                    f"{vehicle_id}: {status.state.name} -> {to.name} is not allowed")
            status.history.append(
                Transition(self._clock.today(), status.state, to, reason))
            status.state = to
            if branch_id is not None:
                status.branch_id = branch_id
            self._statuses.save(status)
            log.info("%s -> %s (%s)", vehicle_id, to.name, reason)
            return status

What to notice. The table is data, not a chain of if statements. Reading it tells you the whole lifecycle in six lines, and a test can check that every state has a row. Notice ON_RENT has exactly one way out. A returned car must pass through inspection, so "the customer dropped the keys and the next customer drove off" cannot happen in this code. Every move also appends a Transition with the date from the injected clock and a reason. That history is the audit trail an ops team asks for in week two.

Step 7 — Damage inspection

Goal: type DamageInspector, which bills only damage the car did not already have.

Type car_rental_v2/inspection.py:

"""Post-return inspection: what is new damage, and what does it cost?

DamageInspector keeps a ledger of the damage each car already carries, so a
customer pays only for what is new. assess() is pure: it prices the report
and changes nothing. record() commits the new damage once the money side has
succeeded. That split is what makes a retried inspection safe.
"""
import threading
from collections.abc import Iterable
from dataclasses import dataclass

from .config import InspectionConfig
from .models import Damage, InspectionReport, PriceLine


@dataclass(frozen=True)
class DamageAssessment:
    new_damage: frozenset[Damage]
    lines: tuple[PriceLine, ...]
    needs_repair: bool


class DamageInspector:
    def __init__(self, config: InspectionConfig):
        self._config = config
        self._lock = threading.Lock()   # guards _known
        self._known: dict[str, set[Damage]] = {}

    def known(self, vehicle_id: str) -> frozenset[Damage]:
        with self._lock:
            return frozenset(self._known.get(vehicle_id, set()))

    def record(self, vehicle_id: str, damages: Iterable[Damage]) -> None:
        """Add damage to the car's ledger (pickup walk-around, or after billing)."""
        with self._lock:
            self._known.setdefault(vehicle_id, set()).update(damages)

    def assess(self, vehicle_id: str, report: InspectionReport) -> DamageAssessment:
        new = report.damages - self.known(vehicle_id)
        ordered = sorted(new, key=lambda d: (d.kind.value, d.panel))
        lines = tuple(
            PriceLine(f"damage: {d.kind.value} ({d.panel})",
                      self._config.damage_charges[d.kind])
            for d in ordered)
        needs_repair = any(d.kind in self._config.needs_repair
                           for d in self.known(vehicle_id) | new)
        return DamageAssessment(frozenset(new), lines, needs_repair)

    def repair(self, vehicle_id: str) -> None:
        """The workshop fixed everything that needed repair."""
        with self._lock:
            known = self._known.get(vehicle_id, set())
            self._known[vehicle_id] = {d for d in known
                                       if d.kind not in self._config.needs_repair}

What to notice. assess is pure. It prices a report and changes nothing. record is the only method that writes. They are split on purpose, and Feature 5 shows why: if the payment fails halfway, nothing was recorded, so the retry still sees the dent as new and still bills it. Fold the two together and a timeout would let the dent through for free.

11.7 Feature 4: several branches, one-way trips

With one branch, "is the car free?" was the only question. With several, there is a second: will the car be there? A car dropped at the airport on Wednesday is not downtown on Thursday, however free its calendar looks.

Step 8 — The branch network

Goal: type the trip repository, BranchNetwork (where the car will be, and whether a route fits), and OneWayFeeRule, the fifth link in the pricing chain.

Type car_rental_v2/branches.py:

"""Multi-branch pickup and drop-off.

A Trip records the branches for a v1 Reservation, keyed by the same id, so
Reservation itself never changes. BranchNetwork answers two questions:
where will this car be on a given day, and does a new trip fit the car's
route without stranding a later booking? OneWayFeeRule adds the fee as one
more link in the pricing chain.
"""
import threading
from abc import ABC, abstractmethod
from collections.abc import Iterable
from datetime import date

from .config import BranchConfig
from .errors import BranchMismatchError, UnknownBranchError
from .lifecycle import VehicleLifecycle
from .models import Branch, PriceLine, Trip, TripStage
from .pricing_rules import PricingContext, PricingRule

# Trips whose drop-off has not happened yet. Once a car is returned, the
# lifecycle status already holds its branch.
_OPEN = frozenset({TripStage.BOOKED, TripStage.PICKED_UP})


class TripRepository(ABC):
    @abstractmethod
    def add(self, trip: Trip) -> None: ...
    @abstractmethod
    def get(self, reservation_id: str) -> Trip | None: ...
    @abstractmethod
    def save(self, trip: Trip) -> None: ...
    @abstractmethod
    def for_vehicle(self, vehicle_id: str) -> list[Trip]:
        """Trips for the vehicle that are not cancelled."""


class InMemoryTrips(TripRepository):
    def __init__(self):
        self._lock = threading.Lock()   # guards _trips
        self._trips: dict[str, Trip] = {}

    def add(self, trip: Trip) -> None:
        with self._lock:
            self._trips[trip.reservation_id] = trip

    def get(self, reservation_id: str) -> Trip | None:
        with self._lock:
            return self._trips.get(reservation_id)

    def save(self, trip: Trip) -> None:
        self.add(trip)

    def for_vehicle(self, vehicle_id: str) -> list[Trip]:
        with self._lock:
            return [t for t in self._trips.values()
                    if t.vehicle_id == vehicle_id
                    and t.stage is not TripStage.CANCELLED]


class BranchNetwork:
    def __init__(self, branches: Iterable[Branch], trips: TripRepository,
                 lifecycle: VehicleLifecycle, config: BranchConfig):
        self._branches = {b.branch_id: b for b in branches}
        self._trips = trips
        self._lifecycle = lifecycle
        self._config = config

    def require(self, branch_id: str) -> Branch:
        branch = self._branches.get(branch_id)
        if branch is None:
            raise UnknownBranchError(f"no branch {branch_id}")
        return branch

    def one_way_fee(self, pickup: str, dropoff: str) -> float:
        if pickup == dropoff:
            return 0.0
        return self._config.one_way_fees.get(
            (pickup, dropoff), self._config.default_one_way_fee)

    def expected_branch(self, vehicle_id: str, on: date) -> str:
        """Where the car will be on `on`: the drop-off of its latest open trip
        ending by then, or where it stands today if no open trip ends first."""
        earlier = [t for t in self._trips.for_vehicle(vehicle_id)
                   if t.stage in _OPEN and t.end_date <= on]
        if earlier:
            return max(earlier, key=lambda t: t.end_date).dropoff_branch
        return self._lifecycle.status(vehicle_id).branch_id

    def check_route(self, vehicle_id: str, start: date, end: date,
                    pickup: str, dropoff: str) -> None:
        self.require(pickup)
        self.require(dropoff)
        here = self.expected_branch(vehicle_id, start)
        if here != pickup:
            raise BranchMismatchError(
                f"{vehicle_id} will be at {here} on {start}, not {pickup}")
        later = [t for t in self._trips.for_vehicle(vehicle_id) if t.start_date >= end]
        if later:
            nxt = min(later, key=lambda t: t.start_date)
            if nxt.pickup_branch != dropoff:
                raise BranchMismatchError(
                    f"dropping {vehicle_id} at {dropoff} strands trip "
                    f"{nxt.reservation_id}, which starts at {nxt.pickup_branch} "
                    f"on {nxt.start_date}")


class OneWayFeeRule(PricingRule):
    """A flat fee. Put it after the discounts so nobody discounts it."""

    def __init__(self, network: BranchNetwork, trips: TripRepository):
        self._network = network
        self._trips = trips

    def adjust(self, ctx: PricingContext, subtotal: float) -> PriceLine | None:
        trip = self._trips.get(ctx.reservation.reservation_id)
        if trip is None or not trip.one_way:
            return None
        fee = self._network.one_way_fee(trip.pickup_branch, trip.dropoff_branch)
        return PriceLine(f"one-way {trip.pickup_branch}->{trip.dropoff_branch}", fee)

What to notice. check_route asks two questions. Looking back: will the car be at the pickup branch on the start date? Looking forward: will the drop-off branch match where the next trip starts? The second check is the one candidates forget. Without it, a one-way booking made today can quietly strand a round trip someone booked last week.

And look at OneWayFeeRule. It lives in this file, not in pricing_rules.py, and the chain never heard of it. The chain was closed when you typed Step 4. This is the first proof that the closure holds.

11.8 Feature 5: payments that cannot double-charge

This is the follow-up that separates senior answers from the rest. The flow itself is ordinary. At pickup you hold the quote plus a deposit on the card. At settlement you capture what is owed, release the rest, and charge separately for anything over the hold. The hard part is failure. A timeout tells you nothing. The money may have moved, or it may not.

The fix is the contract every serious card processor offers: an idempotency key. Send the same key twice and the second call returns the first result instead of moving money again. PaymentService builds each key from the reservation id and the step, so a retry always reuses the same keys.

Step 9 — The gateway seam and the payment service

Goal: type the injected PaymentGateway, an in-memory fake that keeps the idempotency contract, and PaymentService.

Type car_rental_v2/payments.py:

"""Payments: deposit hold at pickup, capture and release at settlement.

PaymentGateway is the seam to a card processor. Every call carries an
idempotency key, the same contract real processors offer: send the same key
twice and the second call returns the first result instead of moving money
again. PaymentService derives each key from the reservation id and the step
("r1:hold", "r1:capture", ...), so a retry after a timeout replays the same
keys and cannot double-charge.
"""
import itertools
import logging
import threading
from abc import ABC, abstractmethod
from collections.abc import Callable
from dataclasses import dataclass

from .errors import IdempotencyConflictError, PaymentStateError

log = logging.getLogger(__name__)


class PaymentGateway(ABC):
    @abstractmethod
    def hold(self, amount: float, key: str) -> str:
        """Reserve funds on the card. Returns a hold id."""

    @abstractmethod
    def capture(self, hold_id: str, amount: float, key: str) -> str:
        """Take up to the held amount. Returns a transaction id."""

    @abstractmethod
    def release(self, hold_id: str, key: str) -> str:
        """Free whatever is still held. Returns a transaction id."""

    @abstractmethod
    def charge(self, amount: float, key: str) -> str:
        """A plain charge with no hold. Returns a transaction id."""


@dataclass
class _Hold:
    amount: float
    captured: float = 0.0
    released: bool = False


class InMemoryPaymentGateway(PaymentGateway):
    """A fake that keeps the idempotency contract, so tests exercise retries."""

    def __init__(self):
        self._lock = threading.Lock()   # guards everything below
        self._results: dict[str, tuple[tuple, str]] = {}
        self._holds: dict[str, _Hold] = {}
        self._ids = itertools.count(1)
        self.executed: list[str] = []   # operations that really moved money

    def _once(self, key: str, request: tuple, action: Callable[[], str]) -> str:
        with self._lock:
            if key in self._results:
                seen_request, result = self._results[key]
                if seen_request != request:
                    raise IdempotencyConflictError(
                        f"key {key} reused for a different request")
                return result
            result = action()
            self._results[key] = (request, result)
            self.executed.append(f"{result}: " + " ".join(map(str, request)))
            return result

    def _new_id(self, prefix: str) -> str:
        return f"{prefix}{next(self._ids)}"

    def hold(self, amount: float, key: str) -> str:
        def act() -> str:
            hold_id = self._new_id("H")
            self._holds[hold_id] = _Hold(amount)
            return hold_id
        return self._once(key, ("hold", amount), act)

    def capture(self, hold_id: str, amount: float, key: str) -> str:
        def act() -> str:
            hold = self._holds[hold_id]
            if hold.released or amount > hold.amount - hold.captured:
                raise PaymentStateError(f"cannot capture {amount} on {hold_id}")
            hold.captured = round(hold.captured + amount, 2)
            return self._new_id("C")
        return self._once(key, ("capture", hold_id, amount), act)

    def release(self, hold_id: str, key: str) -> str:
        def act() -> str:
            self._holds[hold_id].released = True
            return self._new_id("R")
        return self._once(key, ("release", hold_id), act)

    def charge(self, amount: float, key: str) -> str:
        return self._once(key, ("charge", amount), lambda: self._new_id("X"))

    def held(self, hold_id: str) -> float:
        with self._lock:
            hold = self._holds[hold_id]
            return 0.0 if hold.released else round(hold.amount - hold.captured, 2)


@dataclass(frozen=True)
class Settlement:
    reservation_id: str
    final: float
    captured: float
    released: float
    extra_charged: float


@dataclass
class PaymentRecord:
    reservation_id: str
    hold_id: str
    held: float
    settlement: Settlement | None = None


class PaymentService:
    def __init__(self, gateway: PaymentGateway):
        self._gateway = gateway
        self._lock = threading.RLock()   # one settlement at a time per service
        self._records: dict[str, PaymentRecord] = {}

    def record(self, reservation_id: str) -> PaymentRecord | None:
        with self._lock:
            return self._records.get(reservation_id)

    def place_hold(self, reservation_id: str, amount: float) -> PaymentRecord:
        if amount <= 0:
            raise ValueError("hold amount must be positive")
        with self._lock:
            existing = self._records.get(reservation_id)
            if existing is not None:
                return existing
            amount = round(amount, 2)
            hold_id = self._gateway.hold(amount, f"{reservation_id}:hold")
            record = PaymentRecord(reservation_id, hold_id, amount)
            self._records[reservation_id] = record
            log.info("hold %s: $%.2f for %s", hold_id, amount, reservation_id)
            return record

    def settle(self, reservation_id: str, final: float) -> Settlement:
        """Capture what is owed from the hold, release the rest, charge any excess."""
        if final < 0:
            raise ValueError("final amount must be >= 0")
        final = round(final, 2)
        with self._lock:
            record = self._records.get(reservation_id)
            if record is None:
                raise PaymentStateError(f"no hold for {reservation_id}")
            if record.settlement is not None:
                if record.settlement.final != final:
                    raise IdempotencyConflictError(
                        f"{reservation_id} already settled at "
                        f"${record.settlement.final:.2f}")
                return record.settlement
            rid, hold_id = reservation_id, record.hold_id
            captured = min(final, record.held)
            if captured > 0:
                self._gateway.capture(hold_id, captured, f"{rid}:capture")
            released = round(record.held - captured, 2)
            if released > 0:
                self._gateway.release(hold_id, f"{rid}:release")
            extra = round(final - captured, 2)
            if extra > 0:
                self._gateway.charge(extra, f"{rid}:extra")
            record.settlement = Settlement(rid, final, captured, released, extra)
            log.info("settled %s: final $%.2f", rid, final)
            return record.settlement

What to notice. The keys are deterministic: "r1:hold", "r1:capture", "r1:release", "r1:extra". A random key per attempt would defeat the purpose, because a retry would look like a new request. The fake gateway also refuses a key reused for a different request. That catches the bug where two code paths share a key by accident. And there are two layers of idempotency. The gateway dedupes each call. The service remembers each settlement and returns it again, so a double-clicked "settle" button never reaches the gateway at all.

@dataclass(frozen=True)
class ReturnSummary:
    reservation_id: str
    quoted_total: float
    extras: tuple[PriceLine, ...]
    final: float
    settlement: Settlement
    next_state: VehicleState


class RentalDesk:
    def __init__(self, *, rental: RentalService, fleet: FleetRepository,
                 reservations: ReservationRepository,
                 pricing: RuleChainPricing, lifecycle: VehicleLifecycle,
                 network: BranchNetwork, trips: TripRepository,
                 inspector: DamageInspector, return_rules: Sequence[ReturnRule],
                 payments: PaymentService, clock: Clock,
                 config: V2Config, rental_config: RentalConfig):
        self._rental = rental
        self._fleet = fleet
        self._reservations = reservations   # the same repo v1 was given
        self._pricing = pricing
        self._lifecycle = lifecycle
        self._network = network
        self._trips = trips
        self._inspector = inspector
        self._return_rules = list(return_rules)
        self._payments = payments
        self._clock = clock
        self._config = config
        self._rental_config = rental_config
        self._lock = threading.RLock()   # one use case at a time, end to end

    # -- fleet --------------------------------------------------------------

    def add_vehicle(self, vehicle_id: str, category: VehicleCategory, make: str,
                    model: str, year: int, branch_id: str) -> Vehicle:
        with self._lock:
            self._network.require(branch_id)
            vehicle = self._rental.add_vehicle(vehicle_id, category, make, model, year)
            self._lifecycle.register(vehicle.vehicle_id, branch_id)
            return vehicle

    def add_ev(self, vehicle_id: str, category: VehicleCategory, make: str,
               model: str, year: int, branch_id: str, *,
               battery_kwh: float, charge_pct: int) -> ElectricVehicle:
        if battery_kwh <= 0:
            raise ValueError("battery_kwh must be positive")
        if not 0 <= charge_pct <= 100:
            raise ValueError("charge_pct must be within 0..100")
        with self._lock:
            self._network.require(branch_id)
            if self._fleet.get(vehicle_id) is not None:
                raise DuplicateVehicleError(f"vehicle {vehicle_id} already exists")
            ev = ElectricVehicle(vehicle_id, category, make, model, year,
                                 battery_kwh=battery_kwh, charge_pct=charge_pct)
            self._fleet.add(ev)
            self._lifecycle.register(vehicle_id, branch_id)
            log.info("added EV %s at %d%%", vehicle_id, charge_pct)
            return ev

    # -- booking ------------------------------------------------------------

    def search(self, category: VehicleCategory, start: date, end: date,
               branch_id: str) -> list[Vehicle]:
        """v1 search, then: not retired or in the workshop, and at the branch."""
        self._network.require(branch_id)
        blocked = {VehicleState.RETIRED, VehicleState.MAINTENANCE}
        return [v for v in self._rental.search_available(category, start, end)
                if self._lifecycle.status(v.vehicle_id).state not in blocked
                and self._network.expected_branch(v.vehicle_id, start) == branch_id]

    def book(self, vehicle_id: str, customer_name: str, start: date, end: date,
             pickup_branch: str, dropoff_branch: str | None = None,
             add_ons: AddOns | None = None) -> Trip:
        dropoff_branch = dropoff_branch or pickup_branch
        with self._lock:
            if self._lifecycle.status(vehicle_id).state is VehicleState.RETIRED:
                raise VehicleNotReadyError(f"{vehicle_id} is retired")
            self._network.check_route(vehicle_id, start, end,
                                      pickup_branch, dropoff_branch)
            reservation = self._rental.reserve(vehicle_id, customer_name,
                                               start, end, add_ons)
            trip = Trip(reservation.reservation_id, vehicle_id,
                        reservation.customer_name, start, end,
                        pickup_branch, dropoff_branch)
            self._trips.add(trip)   # before pricing: OneWayFeeRule reads it
            trip.quoted_total = self.quote(trip.reservation_id).total
            self._trips.save(trip)
            log.info("booked %s, price locked at $%.2f",
                     trip.reservation_id, trip.quoted_total)
            return trip

    def quote(self, reservation_id: str) -> Quote:
        """Today's itemised price. The trip keeps the total locked at booking."""
        trip = self._trip(reservation_id)
        reservation = self._reservations.get(reservation_id)
        vehicle = self._fleet.get(trip.vehicle_id)
        return self._pricing.explain(vehicle, reservation, self._rental_config)

    def cancel(self, reservation_id: str) -> None:
        with self._lock:
            trip = self._trip(reservation_id)
            self._require_stage(trip, TripStage.BOOKED)
            self._rental.cancel(reservation_id)
            trip.stage = TripStage.CANCELLED
            self._trips.save(trip)

    # -- the rental itself --------------------------------------------------

    def pick_up(self, reservation_id: str,
                walkaround: Iterable[Damage] = ()) -> PaymentRecord:
        with self._lock:
            trip = self._trip(reservation_id)
            self._require_stage(trip, TripStage.BOOKED)
            today = self._clock.today()
            if not trip.start_date <= today < trip.end_date:
                raise RentalStageError(
                    f"pickup for {reservation_id} is {trip.start_date}, today is {today}")
            vehicle = self._fleet.get(trip.vehicle_id)
            self._check_ready(vehicle, trip.pickup_branch)
            deposit = self._config.payments.deposits[vehicle.category]
            record = self._payments.place_hold(reservation_id,
                                               trip.quoted_total + deposit)
            self._lifecycle.transition(vehicle.vehicle_id, VehicleState.ON_RENT,
                                       f"pickup {reservation_id}")
            self._inspector.record(vehicle.vehicle_id, walkaround)
            trip.stage = TripStage.PICKED_UP
            self._trips.save(trip)
            return record

    def return_vehicle(self, reservation_id: str) -> None:
        """Keys back at the drop-off branch. The car waits for inspection."""
        with self._lock:
            trip = self._trip(reservation_id)
            self._require_stage(trip, TripStage.PICKED_UP)
            self._lifecycle.transition(trip.vehicle_id, VehicleState.AWAITING_INSPECTION,
                                       f"return {reservation_id}",
                                       branch_id=trip.dropoff_branch)
            trip.late_fee = self._rental.return_vehicle(reservation_id,
                                                        self._clock.today())
            trip.stage = TripStage.RETURNED
            self._trips.save(trip)

    def complete_inspection(self, reservation_id: str,
                            report: InspectionReport) -> ReturnSummary:
        with self._lock:
            trip = self._trip(reservation_id)
            self._require_stage(trip, TripStage.RETURNED)
            vehicle = self._fleet.get(trip.vehicle_id)
            extras: list[PriceLine] = []
            if trip.late_fee > 0:
                extras.append(PriceLine("late return", trip.late_fee))
            for rule in self._return_rules:
                extras.extend(rule.charges(vehicle, report))
            assessment = self._inspector.assess(vehicle.vehicle_id, report)
            extras.extend(assessment.lines)
            final = round(trip.quoted_total + sum(x.amount for x in extras), 2)
            # Money first. If the gateway times out, nothing below has run,
            # and a retry re-prices the same report with the same keys.
            settlement = self._payments.settle(reservation_id, final)
            self._inspector.record(vehicle.vehicle_id, assessment.new_damage)
            if isinstance(vehicle, ElectricVehicle):
                vehicle.charge_pct = report.charge_pct
                self._fleet.add(vehicle)
            next_state = self._next_state(vehicle, assessment.needs_repair)
            self._lifecycle.transition(vehicle.vehicle_id, next_state,
                                       f"inspected {reservation_id}")
            trip.stage = TripStage.CLOSED
            self._trips.save(trip)
            return ReturnSummary(reservation_id, trip.quoted_total, tuple(extras),
                                 final, settlement, next_state)

    # -- workshop and chargers ---------------------------------------------

    def send_to_maintenance(self, vehicle_id: str, reason: str) -> None:
        self._lifecycle.transition(vehicle_id, VehicleState.MAINTENANCE, reason)

    def finish_maintenance(self, vehicle_id: str) -> None:
        with self._lock:
            self._lifecycle.transition(vehicle_id, VehicleState.AVAILABLE, "repaired")
            self._inspector.repair(vehicle_id)

    def finish_charging(self, vehicle_id: str, charge_pct: int) -> None:
        with self._lock:
            vehicle = self._fleet.get(vehicle_id)
            if not isinstance(vehicle, ElectricVehicle):
                raise ValueError(f"{vehicle_id} is not electric")
            if charge_pct < self._config.ev.min_pickup_charge_pct or charge_pct > 100:
                raise ValueError(f"charge_pct {charge_pct} is not rentable")
            vehicle.charge_pct = charge_pct
            self._fleet.add(vehicle)
            self._lifecycle.transition(vehicle_id, VehicleState.AVAILABLE,
                                       f"charged to {charge_pct}%")

    def retire(self, vehicle_id: str) -> None:
        self._lifecycle.transition(vehicle_id, VehicleState.RETIRED, "retired")

    def status(self, vehicle_id: str) -> VehicleStatus:
        return self._lifecycle.status(vehicle_id)

    # -- helpers ------------------------------------------------------------

    def _trip(self, reservation_id: str) -> Trip:
        trip = self._trips.get(reservation_id)
        if trip is None:
            raise TripNotFoundError(f"no trip {reservation_id}")
        return trip

    @staticmethod
    def _require_stage(trip: Trip, stage: TripStage) -> None:
        if trip.stage is not stage:
            raise RentalStageError(
                f"{trip.reservation_id} is {trip.stage.name}, expected {stage.name}")

    def _check_ready(self, vehicle: Vehicle, branch_id: str) -> None:
        status = self._lifecycle.status(vehicle.vehicle_id)
        if status.state is not VehicleState.AVAILABLE:
            raise VehicleNotReadyError(f"{vehicle.vehicle_id} is {status.state.name}")
        if status.branch_id != branch_id:
            raise VehicleNotReadyError(
                f"{vehicle.vehicle_id} is at {status.branch_id}, not {branch_id}")
        if (isinstance(vehicle, ElectricVehicle)
                and vehicle.charge_pct < self._config.ev.min_pickup_charge_pct):
            raise VehicleNotReadyError(
                f"{vehicle.vehicle_id} is at {vehicle.charge_pct}% charge")

    def _next_state(self, vehicle: Vehicle, needs_repair: bool) -> VehicleState:
        if needs_repair:
            return VehicleState.MAINTENANCE
        if (isinstance(vehicle, ElectricVehicle)
                and vehicle.charge_pct < self._config.ev.min_pickup_charge_pct):
            return VehicleState.CHARGING
        return VehicleState.AVAILABLE

What to notice. Follow complete_inspection from top to bottom. It reads the late fee that version 1's return_vehicle computed. It runs every return rule, then asks the inspector to price the damage. It settles the money. Only then does it record the damage, update the battery and move the car. The comment in the middle marks the line that makes retries safe.

Also notice what the desk does not do. It never validates a booking window (version 1's factory does). It never looks for overlaps (version 1's repository does). It never computes a price (the chain does). It coordinates, holds one lock, and stays out of everyone else's job.

def build_desk(*, clock: Clock, gateway: PaymentGateway, branches: Iterable[Branch],
               loyalty: dict[str, LoyaltyTier] | None = None,
               config: V2Config | None = None,
               rental_config: RentalConfig | None = None) -> RentalDesk:

    rental_config = rental_config or RentalConfig()

    fleet = InMemoryFleet()
    reservations = InMemoryReservations()
    lifecycle = VehicleLifecycle(InMemoryStatuses(), clock)
    trips = InMemoryTrips()
    network = BranchNetwork(branches, trips, lifecycle, config.branches)

    pricing = RuleChainPricing(
        rules=[WeekendRule(), SurgeRule(),            # surcharges
               LongRentalDiscount(), LoyaltyDiscount(),   # discounts
               OneWayFeeRule(network, trips)],         # flat fee, never discounted
        rules_config=config.pricing,
        utilisation=FleetUtilisation(fleet, reservations),
        loyalty=InMemoryLoyalty(loyalty),
    )
    rental = RentalService(fleet=fleet, reservations=reservations, pricing=pricing,
                           factory=ReservationFactory(fleet, clock),
                           clock=clock, config=rental_config)
    return RentalDesk(
        rental=rental, fleet=fleet, reservations=reservations, pricing=pricing,
        lifecycle=lifecycle, network=network, trips=trips,
        inspector=DamageInspector(config.inspection),
        return_rules=[LowChargeRule(config.ev)],
        payments=PaymentService(gateway),
        clock=clock, config=config, rental_config=rental_config,
    )

class LostResponseGateway(PaymentGateway):
    """Does the work, then 'loses' the reply once for the named operation:
    the nastiest failure, because the money really moved."""

    def __init__(self, inner: InMemoryPaymentGateway, fail_once_on: str):
        self.inner = inner
        self._fail_once_on = fail_once_on

    def _maybe_fail(self, op: str) -> None:
        if op == self._fail_once_on:
            self._fail_once_on = ""
            raise GatewayTimeoutError(f"{op}: no response")

    def hold(self, amount, key):
        result = self.inner.hold(amount, key)
        self._maybe_fail("hold")
        return result

    def capture(self, hold_id, amount, key):
        result = self.inner.capture(hold_id, amount, key)
        self._maybe_fail("capture")
        return result

    def release(self, hold_id, key):
        result = self.inner.release(hold_id, key)
        self._maybe_fail("release")
        return result

    def charge(self, amount, key):
        result = self.inner.charge(amount, key)
        self._maybe_fail("charge")
        return result

Honest limits. The desk's single RLock makes every use case atomic, but it also serialises them. A busy branch would want one lock per vehicle. The payment service holds its lock during gateway calls; with a real network that lock should cover only the record, with idempotency keys guarding the rest.

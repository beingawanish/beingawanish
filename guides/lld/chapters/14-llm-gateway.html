Chapter 14: LLM Gateway

Type every file in order. Run each checkpoint before moving on. All commands run from the project folder (the one holding llm_gateway/ and tests/). Python 3.13, stdlib only. No network: every model provider in this chapter is a fake.

1. The problem

Your company has twenty teams calling large language models. Each team picked its own provider, wrote its own retry loop, and pasted an API key into its own config. Nobody knows what the monthly bill will be until it arrives. When one provider has a bad afternoon, a dozen services fail in a dozen different ways.

The fix is an internal LLM gateway: one service every team calls instead of calling a model provider directly. Teams send a single request shape. The gateway picks the model, retries what is worth retrying, falls back to another provider when one is down, enforces each team's rate limits and token budget, bills every token to the right team, caches repeat questions, scrubs personal data on the way in and out, and writes an audit trail that never contains the prompt itself.

That sounds like a lot. It is a lot. But each concern turns out to be one small class, and the gateway itself is mostly a fixed sequence of calls to them. That shape — a thin orchestrator over many single-purpose collaborators — is exactly what the interviewer wants to see.

Scope for this chapter: synchronous request and response, in one process. Streaming and semantic caching come up as follow-ups in section 9, with the design change each one needs.

2. Requirements

This is a 2026 question, so expect the interviewer to care less about class names and more about whether you have run LLM traffic in production. Ask before you design. These are the questions a strong candidate asks, with the answers this chapter assumes.

Clarifying questions

  • Who calls the gateway, and how do we know who they are? Internal teams, each identified by a team id. Authentication happens upstream; the gateway trusts the team id it receives.
  • Do callers name a model, or describe the job? Both. A caller can name a route alias such as smart or fast, or a task such as summarise. Teams should not hard-code vendor model ids.
  • Can a request fail over to a different provider? Yes, inside the route's chain. (In real life, ask whether legal has approved every provider for every team's data. The answer shapes the chain.)
  • What counts against a team's budget: our estimate or the real usage? Real usage. The estimate only gates admission.
  • Who pays for a failed request? Nobody: if no model produced output, the team's tokens are refunded. A response blocked by an output guardrail still costs money, because the provider still generated it.
  • Is streaming in scope? Not for the first version. Design so it can be added.
  • Can we cache answers? Exact repeats only, at temperature 0, and never across teams.
  • What may the audit log contain? Metadata only. Prompts can hold customer data, secrets and unreleased plans; the log must not.

Functional

  • One unified request type (ChatRequest) and response type (ChatResponse), whatever the provider.
  • Routing: a route alias maps to an ordered chain of models; a task maps to an alias. The team's maximum cost tier filters the chain.
  • Fallback: on a provider error or timeout, move to the next model in the chain. A per-model circuit breaker skips a model that keeps failing.
  • Retries with exponential backoff and full jitter, for retryable errors only (rate limited 429, overloaded 529, server error 500, timeout). A bad request (400) fails at once and never falls back.
  • Per-team rate limits (requests per minute, tokens per minute) and a per-team token budget.
  • Token accounting from the usage the provider reports, priced into a cost ledger.
  • An exact-match response cache keyed on the normalised request.
  • Guardrail hooks on request and response, run as a chain: PII redaction and blocked content to start with.
  • An audit record for every request, with no prompt or response text in it.

Non-functional

  • Providers sit behind an injected ModelProvider interface. Tests use a deterministic fake with scriptable failures and latency.
  • Time and randomness are injected: no real sleeping in tests, reproducible jitter.
  • Safe under concurrent calls: two threads must not both squeeze under the same rate limit.
  • Every number (prices, limits, delays, thresholds) lives in config.
  • Typed exception hierarchy; no bare except. Stdlib only.

5. Key design decisions

  1. The gateway is a fixed pipeline over single-purpose collaborators. complete() runs guardrails, routing, cache, quota, the fallback chain, settlement, ledger, output guardrails, cache store and audit, always in that order. Each step is one call to one object. Change how quotas work and you touch QuotaManager, nothing else.
  2. Errors carry a retryable flag, and everything keys off it. The retrier retries only retryable errors. The breaker counts only retryable errors. The fallback loop moves on only after retryable errors. A 400 means your request is wrong. Retrying it, or sending it to another provider, just burns money and time to get the same answer.
  3. Retry inside a model, fall back across models. Each model in the chain gets a few attempts with backoff. Only when those are exhausted does the gateway move on. The breaker sits inside the retrier, so once it opens, the remaining attempts fail instantly instead of waiting on a provider that is down.
  4. Full jitter, and the provider's retry-after hint wins. Without jitter, a hundred clients that failed together retry together, and knock the provider over again. Full jitter (a random delay between zero and the exponential ceiling) spreads them out. When a 429 says "retry after 2 seconds", the gateway believes it. When the hint is longer than the configured maximum wait, the gateway gives up on that model at once and falls back.
  5. Quotas reserve an estimate, then settle to the truth. Nobody knows how many tokens a reply will use until it arrives. So admission reserves the worst case (prompt tokens plus max_tokens) under a lock, which makes check-then-reserve atomic. After the call, settle swaps in the real count. If every provider failed, release refunds the tokens but keeps the request counted.
  6. Money is Decimal, priced from reported usage. Prices are per million tokens, and cost is quantised to a millionth of a dollar. Floats would drift; a ledger that disagrees with the invoice by a few cents is a ledger finance stops trusting.
  7. The cache key is a fingerprint of the normalised request, scoped to the team. Whitespace is collapsed, case is kept. Only temperature-0 requests are cached, since a higher temperature asks for variety. The same SHA-256 fingerprint goes into the audit record, so you can spot duplicate traffic without storing the text.
  8. Guardrails are a chain, and order matters. Redaction before blocking means the blocker never sees raw PII. The chain is itself a Guardrail, so chains nest.

Patterns, and why each earns its place. Strategy for routing: a latency-aware router is a new class, not an edit. Chain of Responsibility (in its pipeline form) for guardrails: each hook may rewrite or reject. Circuit Breaker and Retry with backoff: the two standard stability patterns, kept as separate classes because they answer different questions — "should I wait and try again?" versus "should I even try?". Adapter for providers: each vendor's SDK is wrapped behind ModelProvider, and its error codes are mapped onto the gateway's typed errors.

Step 1 — Configuration: models, prices, routes, teams

Goal: create the one place where every price, limit, delay and route lives.

Type llm_gateway/config.py:

"""Configuration: models, prices, routes, team policies and every tunable.

Nothing in the gateway contains a literal price, limit or delay. Routes name
models by key ("provider/model"), and __post_init__ rejects a route that
points at a model nobody configured, so a typo fails at startup, not at 3 a.m.
"""
from dataclasses import dataclass, field
from decimal import Decimal
from enum import IntEnum


class CostTier(IntEnum):
    ECONOMY = 1
    STANDARD = 2
    PREMIUM = 3


@dataclass(frozen=True)
class ModelSpec:
    provider: str
    model: str
    tier: CostTier
    input_usd_per_mtok: Decimal
    output_usd_per_mtok: Decimal

    @property
    def key(self) -> str:
        return f"{self.provider}/{self.model}"


@dataclass(frozen=True)
class TeamPolicy:
    requests_per_minute: int
    tokens_per_minute: int
    token_budget: int
    max_tier: CostTier = CostTier.PREMIUM

    def __post_init__(self) -> None:
        for name in ("requests_per_minute", "tokens_per_minute", "token_budget"):
            if getattr(self, name) <= 0:
                raise ValueError(f"{name} must be positive")


@dataclass(frozen=True)
class RetryPolicy:
    max_attempts: int = 3
    base_delay_s: float = 0.25
    max_delay_s: float = 4.0

    def __post_init__(self) -> None:
        if self.max_attempts < 1:
            raise ValueError("max_attempts must be at least 1")
        if not 0 < self.base_delay_s <= self.max_delay_s:
            raise ValueError("need 0 < base_delay_s <= max_delay_s")


@dataclass(frozen=True)
class BreakerPolicy:
    failure_threshold: int = 3
    cooldown_s: float = 30.0


@dataclass(frozen=True)
class CacheConfig:
    ttl_s: float = 300.0
    max_entries: int = 1024


def _default_models() -> dict[str, ModelSpec]:
    specs = [
        ModelSpec("alpha", "alpha-large", CostTier.PREMIUM, Decimal("15"), Decimal("75")),
        ModelSpec("alpha", "alpha-small", CostTier.ECONOMY, Decimal("0.80"), Decimal("4")),
        ModelSpec("beta", "beta-large", CostTier.PREMIUM, Decimal("10"), Decimal("30")),
        ModelSpec("beta", "beta-medium", CostTier.STANDARD, Decimal("3"), Decimal("15")),
    ]
    return {spec.key: spec for spec in specs}


def _default_routes() -> dict[str, tuple[str, ...]]:
    return {
        "smart": ("alpha/alpha-large", "beta/beta-large", "beta/beta-medium"),
        "fast": ("alpha/alpha-small", "beta/beta-medium"),
    }


def _default_task_routes() -> dict[str, str]:
    return {"code-review": "smart", "summarise": "fast", "classify": "fast"}


def _default_teams() -> dict[str, TeamPolicy]:
    return {
        "search": TeamPolicy(requests_per_minute=60, tokens_per_minute=100_000,
                             token_budget=5_000_000),
        "support": TeamPolicy(requests_per_minute=30, tokens_per_minute=40_000,
                              token_budget=1_000_000, max_tier=CostTier.STANDARD),
    }


@dataclass(frozen=True)
class GatewayConfig:
    models: dict[str, ModelSpec] = field(default_factory=_default_models)
    routes: dict[str, tuple[str, ...]] = field(default_factory=_default_routes)
    task_routes: dict[str, str] = field(default_factory=_default_task_routes)
    teams: dict[str, TeamPolicy] = field(default_factory=_default_teams)
    retry: RetryPolicy = field(default_factory=RetryPolicy)
    breaker: BreakerPolicy = field(default_factory=BreakerPolicy)
    cache: CacheConfig = field(default_factory=CacheConfig)
    provider_timeout_s: float = 30.0
    rate_window_s: float = 60.0
    chars_per_token: int = 4

    def __post_init__(self) -> None:
        for alias, keys in self.routes.items():
            if not keys:
                raise ValueError(f"route {alias!r} has no models")
            for key in keys:
                if key not in self.models:
                    raise ValueError(f"route {alias!r} names unknown model {key!r}")
        for task, alias in self.task_routes.items():
            if alias not in self.routes:
                raise ValueError(f"task {task!r} maps to unknown route {alias!r}")

What to notice. Routes refer to models by key ("alpha/alpha-large"), not by object, so the config reads like a table. __post_init__ then cross-checks the table: a route naming a model nobody configured fails when the gateway starts, not when the first request takes that path. CostTier is an IntEnum so "at or below the team's tier" is a plain <=. The providers are called alpha and beta on purpose: the design must not care whose models they are.

Step 2 — The clock

Goal: one seam for reading time and for sleeping.

Type llm_gateway/clock.py:

"""Injectable clock. The gateway reads time and sleeps only through this seam,
so tests run backoff, cooldowns and rate windows instantly with FakeClock."""
import threading
import time
from abc import ABC, abstractmethod


class Clock(ABC):
    @abstractmethod
    def now(self) -> float:
        """Seconds on a monotonic scale."""

    @abstractmethod
    def sleep(self, seconds: float) -> None:
        ...


class SystemClock(Clock):
    def now(self) -> float:
        return time.monotonic()

    def sleep(self, seconds: float) -> None:
        time.sleep(seconds)


class FakeClock(Clock):
    """Sleeping advances time instead of blocking. The lock guards _now,
    because the concurrency tests call sleep() from many threads."""

    def __init__(self, start: float = 0.0) -> None:
        self._now = start
        self._lock = threading.Lock()

    def now(self) -> float:
        with self._lock:
            return self._now

    def sleep(self, seconds: float) -> None:
        self.advance(seconds)

    def advance(self, seconds: float) -> None:
        if seconds < 0:
            raise ValueError("time only moves forward")
        with self._lock:
            self._now += seconds

What to notice. Earlier chapters' clocks only told the time. This one also sleeps, because backoff needs to wait. In tests, FakeClock.sleep advances time instead of blocking, so a test that walks through three retries and a 30-second circuit cooldown still runs in milliseconds. The lock is there because the concurrency test calls sleep from twenty threads.

Checkpoint:

python3 -c "

print(c.now())"

Expected output:

Step 3 — The error hierarchy

Goal: type the failures, each tagged with whether trying again can help.

Type llm_gateway/errors.py:

"""Gateway errors. Two families matter most: ProviderError (something upstream
went wrong; `retryable` says whether trying again can help) and QuotaError
(the calling team hit its own limit; no provider was called)."""


class GatewayError(Exception):
    """Base for every error the gateway raises."""


class InvalidGatewayRequestError(GatewayError):
    pass


class UnknownTeamError(GatewayError):
    pass


class RouteNotFoundError(GatewayError):
    pass


class NoEligibleModelError(GatewayError):
    """The route exists, but every model in it is above the team's cost tier."""


class GuardrailViolationError(GatewayError):
    def __init__(self, guardrail: str, reason: str) -> None:
        super().__init__(f"{guardrail}: {reason}")
        self.guardrail = guardrail


class QuotaError(GatewayError):
    pass


class RateLimitExceededError(QuotaError):
    def __init__(self, team: str, limit: str, retry_after_s: float) -> None:
        super().__init__(f"team {team!r} hit its {limit} limit; retry in {retry_after_s:.1f}s")
        self.team = team
        self.retry_after_s = retry_after_s


class BudgetExhaustedError(QuotaError):
    pass


class CircuitOpenError(GatewayError):
    """Not a ProviderError on purpose: the retrier must never retry it."""


class ProviderError(GatewayError):
    retryable: bool = False
    status: int | None = None

    def __init__(self, message: str, retry_after_s: float | None = None) -> None:
        super().__init__(message)
        self.retry_after_s = retry_after_s


class ProviderRateLimitError(ProviderError):
    retryable = True
    status = 429


class ProviderOverloadedError(ProviderError):
    retryable = True
    status = 529


class ProviderServerError(ProviderError):
    retryable = True
    status = 500


class ProviderTimeoutError(ProviderError):
    retryable = True


class ProviderInvalidRequestError(ProviderError):
    retryable = False
    status = 400


class AllProvidersFailedError(GatewayError):
    def __init__(self, alias: str, failures: list[tuple[str, Exception]]) -> None:
        detail = "; ".join(f"{key}: {type(err).__name__}" for key, err in failures)
        super().__init__(f"route {alias!r} exhausted: {detail}")
        self.failures = failures

What to notice. retryable and status are class attributes, so the decision "retry or not" is made once, here, by type. The status codes are the ones you will meet in real provider APIs: 429 for rate limiting and 529 for "overloaded" (Anthropic's API uses 529 for that; many other vendors use 503). A real adapter maps whatever its SDK raises onto these classes. CircuitOpenError deliberately does not inherit from ProviderError. If it did, the retrier would sit there retrying an open circuit.

Step 4 — The unified request and response

Goal: type the one request shape and one response shape every team uses.

Type llm_gateway/models.py:

"""The unified request and response types every team codes against.

Provider adapters translate to and from their own wire formats; nothing
outside providers.py ever sees a provider-specific field name.
"""
from dataclasses import dataclass, field
from decimal import Decimal
from enum import Enum

from .errors import InvalidGatewayRequestError

ROLES = ("user", "assistant")


class StopReason(Enum):
    END_TURN = "end_turn"
    MAX_TOKENS = "max_tokens"
    STOP_SEQUENCE = "stop_sequence"
    REFUSAL = "refusal"


@dataclass(frozen=True)
class Message:
    role: str
    content: str

    def __post_init__(self) -> None:
        if self.role not in ROLES:
            raise InvalidGatewayRequestError(f"role must be one of {ROLES}, got {self.role!r}")
        if not self.content.strip():
            raise InvalidGatewayRequestError("message content must not be blank")


@dataclass(frozen=True)
class ChatRequest:
    """Exactly one of `model` (a route alias such as "smart") or `task`
    (such as "summarise") picks the route."""

    team: str
    messages: tuple[Message, ...]
    model: str | None = None
    task: str | None = None
    system: str = ""
    max_tokens: int = 1024
    temperature: float = 0.0

    def __post_init__(self) -> None:
        if not self.team.strip():
            raise InvalidGatewayRequestError("team must not be blank")
        if not self.messages:
            raise InvalidGatewayRequestError("at least one message is required")
        if self.messages[-1].role != "user":
            raise InvalidGatewayRequestError("the last message must come from the user")
        if (self.model is None) == (self.task is None):
            raise InvalidGatewayRequestError("set exactly one of model or task")
        if self.max_tokens <= 0:
            raise InvalidGatewayRequestError("max_tokens must be positive")
        if not 0.0 <= self.temperature <= 1.0:
            raise InvalidGatewayRequestError("temperature must be within [0, 1]")

    def prompt_text(self) -> str:
        """All the text the model will read: system prompt plus every message."""
        return "\n".join([self.system, *(m.content for m in self.messages)])


@dataclass(frozen=True)
class Usage:
    input_tokens: int
    output_tokens: int

    @property
    def total(self) -> int:
        return self.input_tokens + self.output_tokens


@dataclass(frozen=True)
class ProviderResult:
    """What a provider adapter returns: text, usage, why it stopped."""

    text: str
    usage: Usage
    stop_reason: StopReason


@dataclass(frozen=True)
class ChatResponse:
    request_id: str
    text: str
    provider: str
    model: str
    usage: Usage
    stop_reason: StopReason
    cost_usd: Decimal
    cached: bool = False
    fallbacks: tuple[str, ...] = field(default=())

What to notice. ChatRequest validates itself in __post_init__, so an invalid request cannot exist. Exactly one of model or task must be set; that one rule keeps routing unambiguous. Usage counts input and output tokens separately because providers price them separately, often by a factor of five. StopReason uses provider-neutral names; an adapter maps its vendor's values onto them (for example, one vendor's length becomes MAX_TOKENS). And ProviderResult is what a provider returns. The gateway, not the provider, turns it into a ChatResponse with a request id and a price.

Step 5 — The provider seam and a fake

Goal: type the ModelProvider interface and a deterministic fake that can fail on command.

Type llm_gateway/providers.py:

"""The provider seam. A real adapter wraps one vendor SDK and maps its errors
onto the gateway's ProviderError family (429 -> ProviderRateLimitError,
529 -> ProviderOverloadedError, and so on). FakeProvider is deterministic,
offline, and lets a test script failures and latency."""
import math
import threading
from abc import ABC, abstractmethod
from collections import deque

from .clock import Clock
from .errors import ProviderError, ProviderTimeoutError
from .models import ChatRequest, ProviderResult, StopReason, Usage


class ModelProvider(ABC):
    name: str

    @abstractmethod
    def complete(self, model: str, request: ChatRequest, timeout_s: float) -> ProviderResult:
        """Run one completion, or raise a ProviderError subclass."""


class FakeProvider(ModelProvider):
    """Replies "<model> says: <last user message>". Usage is one token per
    four characters, so tests can predict every number. The lock guards the
    failure script and the call log."""

    CHARS_PER_TOKEN = 4

    def __init__(self, name: str, clock: Clock, latency_s: float = 0.0) -> None:
        self.name = name
        self._clock = clock
        self._latency_s = latency_s
        self._script: deque[ProviderError] = deque()
        self._calls: list[str] = []
        self._lock = threading.Lock()

    def fail_next(self, *errors: ProviderError) -> None:
        with self._lock:
            self._script.extend(errors)

    def set_latency(self, seconds: float) -> None:
        with self._lock:
            self._latency_s = seconds

    @property
    def calls(self) -> list[str]:
        with self._lock:
            return list(self._calls)

    def complete(self, model: str, request: ChatRequest, timeout_s: float) -> ProviderResult:
        with self._lock:
            self._calls.append(model)
            scripted = self._script.popleft() if self._script else None
            latency = self._latency_s
        if latency > timeout_s:
            self._clock.sleep(timeout_s)
            raise ProviderTimeoutError(f"{self.name}/{model} took longer than {timeout_s}s")
        self._clock.sleep(latency)
        if scripted is not None:
            raise scripted
        return self._reply(model, request)

    def _reply(self, model: str, request: ChatRequest) -> ProviderResult:
        text = f"{model} says: {request.messages[-1].content}"
        output_tokens = math.ceil(len(text) / self.CHARS_PER_TOKEN)
        stop = StopReason.END_TURN
        if output_tokens > request.max_tokens:
            text = text[: request.max_tokens * self.CHARS_PER_TOKEN]
            output_tokens = request.max_tokens
            stop = StopReason.MAX_TOKENS
        input_tokens = math.ceil(len(request.prompt_text()) / self.CHARS_PER_TOKEN)
        return ProviderResult(text, Usage(input_tokens, output_tokens), stop)

What to notice. The fake is as important as the interface. fail_next queues errors to raise on the next calls, so a test can say "the next three calls are 529s" in one line. Latency goes through the injected clock. If the latency exceeds the timeout, the fake waits out the timeout and raises ProviderTimeoutError, just as a real SDK call with a deadline would. Token counts are one per four characters, a rough rule of thumb for English text. It is crude, but it makes every number in the tests predictable.

Checkpoint:

Step 6 — Routing

Goal: turn a request into an ordered chain of models, filtered by the team's cost tier.

Type llm_gateway/routing.py:

"""Routing: turn a request into an ordered fallback chain of models.

A route alias ("smart", "fast") names a chain. A task ("summarise") maps to an
alias, so callers can say what they want done instead of which model does it.
The team's cost tier then filters the chain: a STANDARD team asking for
"smart" gets only the STANDARD-or-cheaper models in that chain.
"""
from abc import ABC, abstractmethod
from dataclasses import dataclass

from .config import GatewayConfig, ModelSpec, TeamPolicy
from .errors import NoEligibleModelError, RouteNotFoundError
from .models import ChatRequest


@dataclass(frozen=True)
class RouteDecision:
    alias: str
    targets: tuple[ModelSpec, ...]


class RoutingStrategy(ABC):
    @abstractmethod
    def route(self, request: ChatRequest, policy: TeamPolicy) -> RouteDecision:
        ...


class TableRouter(RoutingStrategy):
    def __init__(self, config: GatewayConfig) -> None:
        self._config = config

    def route(self, request: ChatRequest, policy: TeamPolicy) -> RouteDecision:
        alias = self._resolve_alias(request)
        chain = [self._config.models[key] for key in self._config.routes[alias]]
        allowed = tuple(spec for spec in chain if spec.tier <= policy.max_tier)
        if not allowed:
            raise NoEligibleModelError(
                f"route {alias!r} has no model at or below tier {policy.max_tier.name}")
        return RouteDecision(alias, allowed)

    def _resolve_alias(self, request: ChatRequest) -> str:
        if request.task is not None:
            alias = self._config.task_routes.get(request.task)
            if alias is None:
                raise RouteNotFoundError(f"no route for task {request.task!r}")
            return alias
        assert request.model is not None  # ChatRequest guarantees one of the two
        if request.model not in self._config.routes:
            raise RouteNotFoundError(f"no route alias {request.model!r}")
        return request.model

Step 7 — Retries and the circuit breaker

Goal: type the retrier (backoff, jitter, retryable only) and the per-model breaker.

Type llm_gateway/resilience.py:

"""Retries with backoff and jitter, and a circuit breaker per model.

The retrier retries only errors whose `retryable` flag is set. A 400 fails
fast; a 429 or 529 waits and tries again. The breaker counts only retryable
failures too: a malformed request says nothing about the provider's health.
"""
import logging
import random
import threading
from collections.abc import Callable
from enum import Enum
from typing import TypeVar

from .clock import Clock
from .config import BreakerPolicy, RetryPolicy
from .errors import CircuitOpenError, ProviderError

log = logging.getLogger(__name__)
T = TypeVar("T")


class Retrier:
    def __init__(self, policy: RetryPolicy, clock: Clock, rng: random.Random) -> None:
        self._policy = policy
        self._clock = clock
        self._rng = rng

    def delay_for(self, attempt: int, error: ProviderError) -> float:
        """Full jitter: uniform in [0, min(max, base * 2**attempt)].
        A provider's retry-after hint wins when it gives one."""
        if error.retry_after_s is not None:
            return error.retry_after_s
        ceiling = min(self._policy.max_delay_s, self._policy.base_delay_s * 2 ** attempt)
        return self._rng.uniform(0.0, ceiling)

    def run(self, operation: Callable[[], T]) -> T:
        for attempt in range(self._policy.max_attempts):
            try:
                return operation()
            except ProviderError as err:
                last_try = attempt == self._policy.max_attempts - 1
                if not err.retryable or last_try:
                    raise
                delay = self.delay_for(attempt, err)
                if delay > self._policy.max_delay_s:
                    log.info("retry-after %.1fs exceeds max wait; giving up", delay)
                    raise
                log.info("attempt %d failed (%s); retrying in %.3fs",
                         attempt + 1, type(err).__name__, delay)
                self._clock.sleep(delay)
        raise AssertionError("unreachable: the loop returns or raises")


class BreakerState(Enum):
    CLOSED = "closed"
    OPEN = "open"
    HALF_OPEN = "half_open"


class CircuitBreaker:
    """CLOSED -> OPEN after `failure_threshold` consecutive retryable failures.
    OPEN -> HALF_OPEN once `cooldown_s` has passed; exactly one trial call goes
    through. Trial success closes the circuit; trial failure reopens it.
    The lock guards state, the failure count and the trial flag."""

    def __init__(self, name: str, policy: BreakerPolicy, clock: Clock) -> None:
        self.name = name
        self._policy = policy
        self._clock = clock
        self._lock = threading.Lock()
        self._state = BreakerState.CLOSED
        self._failures = 0
        self._opened_at = 0.0
        self._trial_in_flight = False

    @property
    def state(self) -> BreakerState:
        with self._lock:
            return self._current_state()

    def call(self, operation: Callable[[], T]) -> T:
        self._before_call()
        try:
            result = operation()
        except ProviderError as err:
            self._after_failure(err)
            raise
        self._after_success()
        return result

    def _current_state(self) -> BreakerState:
        cooled = self._clock.now() - self._opened_at >= self._policy.cooldown_s
        if self._state is BreakerState.OPEN and cooled:
            self._state = BreakerState.HALF_OPEN
        return self._state

    def _before_call(self) -> None:
        with self._lock:
            state = self._current_state()
            if state is BreakerState.OPEN:
                raise CircuitOpenError(f"circuit for {self.name} is open")
            if state is BreakerState.HALF_OPEN:
                if self._trial_in_flight:
                    raise CircuitOpenError(f"circuit for {self.name} is testing")
                self._trial_in_flight = True

    def _after_success(self) -> None:
        with self._lock:
            if self._state is not BreakerState.CLOSED:
                log.info("circuit for %s closed", self.name)
            self._state = BreakerState.CLOSED
            self._failures = 0
            self._trial_in_flight = False

    def _after_failure(self, err: ProviderError) -> None:
        with self._lock:
            self._trial_in_flight = False
            if not err.retryable:
                return
            self._failures += 1
            trial_failed = self._state is BreakerState.HALF_OPEN
            if trial_failed or self._failures >= self._policy.failure_threshold:
                self._state = BreakerState.OPEN
                self._opened_at = self._clock.now()
                log.warning("circuit for %s opened after %d failures", self.name, self._failures)

What to notice. The retrier knows nothing about providers. It takes any zero-argument callable, so the gateway can hand it "call the breaker, which calls the provider". delay_for is public so a test can check that jitter stays under the capped exponential ceiling. In the breaker, _current_state performs the OPEN to HALF_OPEN move lazily, when someone asks. No timer thread is needed. In HALF_OPEN exactly one trial call goes through; everyone else gets CircuitOpenError until that trial settles the question.

Step 8 — Quotas: rate limits and budgets

Goal: type the per-team sliding window and token budget, with reserve, settle and release.

Type llm_gateway/quotas.py:

"""Per-team rate limits (requests/min, tokens/min) and token budgets.

The true token count is unknown until the model answers, so the gateway
reserves an estimate up front (prompt tokens + max_tokens, the worst case),
then settles to the real usage afterwards, or releases the tokens if every
provider failed. One lock guards every team's window and budget, which keeps
the check-then-reserve step atomic.
"""
import threading
from collections import deque
from collections.abc import Mapping
from dataclasses import dataclass

from .clock import Clock
from .config import TeamPolicy
from .errors import BudgetExhaustedError, RateLimitExceededError, UnknownTeamError


@dataclass
class _WindowEntry:
    at: float
    tokens: int


@dataclass(frozen=True)
class QuotaReservation:
    team: str
    tokens: int
    entry: _WindowEntry


class _TeamState:
    def __init__(self) -> None:
        self.window: deque[_WindowEntry] = deque()
        self.budget_used = 0


class QuotaManager:
    def __init__(self, policies: Mapping[str, TeamPolicy], clock: Clock,
                 window_s: float) -> None:
        self._policies = dict(policies)
        self._clock = clock
        self._window_s = window_s
        self._lock = threading.Lock()
        self._state = {team: _TeamState() for team in self._policies}

    def policy(self, team: str) -> TeamPolicy:
        try:
            return self._policies[team]
        except KeyError:
            raise UnknownTeamError(f"unknown team {team!r}") from None

    def reserve(self, team: str, tokens: int) -> QuotaReservation:
        policy = self.policy(team)
        now = self._clock.now()
        with self._lock:
            state = self._state[team]
            self._prune(state, now)
            if len(state.window) >= policy.requests_per_minute:
                raise RateLimitExceededError(team, "requests/min", self._wait(state, now))
            in_window = sum(entry.tokens for entry in state.window)
            if in_window + tokens > policy.tokens_per_minute:
                raise RateLimitExceededError(team, "tokens/min", self._wait(state, now))
            if state.budget_used + tokens > policy.token_budget:
                raise BudgetExhaustedError(
                    f"team {team!r} would exceed its budget of {policy.token_budget} tokens")
            entry = _WindowEntry(now, tokens)
            state.window.append(entry)
            state.budget_used += tokens
            return QuotaReservation(team, tokens, entry)

    def settle(self, reservation: QuotaReservation, actual_tokens: int) -> None:
        """Swap the estimate for the real count, in the window and the budget."""
        with self._lock:
            state = self._state[reservation.team]
            state.budget_used += actual_tokens - reservation.tokens
            reservation.entry.tokens = actual_tokens

    def release(self, reservation: QuotaReservation) -> None:
        """Nothing was generated: refund the tokens, keep the request counted."""
        self.settle(reservation, 0)

    def budget_remaining(self, team: str) -> int:
        policy = self.policy(team)
        with self._lock:
            return policy.token_budget - self._state[team].budget_used

    def _prune(self, state: _TeamState, now: float) -> None:
        while state.window and now - state.window[0].at >= self._window_s:
            state.window.popleft()

    def _wait(self, state: _TeamState, now: float) -> float:
        return state.window[0].at + self._window_s - now if state.window else 0.0

What to notice. The window is a sliding log: one entry per request, holding its time and token count. Old entries fall off the front. QuotaReservation keeps a reference to its own window entry, so settle can correct the token count in place. That is why _WindowEntry is a mutable dataclass while almost everything else in this chapter is frozen. The error carries retry_after_s, which an HTTP front end would turn into a Retry-After header for the calling team.

Step 9 — The cost ledger

Goal: price reported usage into exact dollars, per team.

Type llm_gateway/ledger.py:

"""Token accounting and the cost ledger.

Cost comes from the usage the provider reported, never from our estimate,
and money is Decimal: a ledger that drifts by float rounding is a ledger
finance stops trusting. The lock guards the entry list.
"""
import threading
from collections.abc import Mapping
from dataclasses import dataclass
from decimal import Decimal

from .clock import Clock
from .config import ModelSpec
from .models import Usage

MTOK = Decimal(1_000_000)
MICRO_DOLLAR = Decimal("0.000001")


@dataclass(frozen=True)
class LedgerEntry:
    request_id: str
    team: str
    model_key: str
    usage: Usage
    cost_usd: Decimal
    at: float


class CostLedger:
    def __init__(self, models: Mapping[str, ModelSpec], clock: Clock) -> None:
        self._models = dict(models)
        self._clock = clock
        self._lock = threading.Lock()
        self._entries: list[LedgerEntry] = []

    def price(self, model_key: str, usage: Usage) -> Decimal:
        spec = self._models[model_key]
        raw = (usage.input_tokens * spec.input_usd_per_mtok
               + usage.output_tokens * spec.output_usd_per_mtok) / MTOK
        return raw.quantize(MICRO_DOLLAR)

    def record(self, request_id: str, team: str, model_key: str, usage: Usage) -> LedgerEntry:
        entry = LedgerEntry(request_id, team, model_key, usage,
                            self.price(model_key, usage), self._clock.now())
        with self._lock:
            self._entries.append(entry)
        return entry

    def total_cost(self, team: str) -> Decimal:
        with self._lock:
            return sum((e.cost_usd for e in self._entries if e.team == team), Decimal("0"))

    def total_tokens(self, team: str) -> int:
        with self._lock:
            return sum(e.usage.total for e in self._entries if e.team == team)

    def entries(self) -> list[LedgerEntry]:
        with self._lock:
            return list(self._entries)

What to notice. The ledger prices reported usage. The estimate from step 8 never reaches it. One thousand input and five hundred output tokens on alpha-large cost 1000 × $15 + 500 × $75, per million: $0.0525. The same call on alpha-small costs $0.0028. That nearly 19-fold spread is why routing by cost tier matters at all.

Step 10 — The exact-match cache

Goal: type the request fingerprint and a TTL plus LRU cache.

Type llm_gateway/cache.py:

"""Exact-match response cache, keyed on a normalised request.

Normalising means: collapse runs of whitespace and trim each text field, so
"Hi  there " and "Hi there" share a key. Case is kept, because case can
change the answer. The key also includes the team (no cross-team leaks) and
the resolved route alias. Only temperature-0 requests are cached; sampling
at a higher temperature asks for variety, and a cache would hide it.
"""
import hashlib
import json
import threading
from collections import OrderedDict

from .clock import Clock
from .config import CacheConfig
from .models import ChatRequest, ChatResponse


def _normalise(text: str) -> str:
    return " ".join(text.split())


def fingerprint(request: ChatRequest, alias: str) -> str:
    """Stable SHA-256 of the normalised request. Also used by the audit log."""
    payload = {
        "team": request.team,
        "alias": alias,
        "system": _normalise(request.system),
        "messages": [[m.role, _normalise(m.content)] for m in request.messages],
        "max_tokens": request.max_tokens,
        "temperature": request.temperature,
    }
    blob = json.dumps(payload, sort_keys=True, separators=(",", ":"))
    return hashlib.sha256(blob.encode()).hexdigest()


class ResponseCache:
    """TTL plus LRU eviction. The lock guards the OrderedDict."""

    def __init__(self, config: CacheConfig, clock: Clock) -> None:
        self._config = config
        self._clock = clock
        self._lock = threading.Lock()
        self._entries: OrderedDict[str, tuple[float, ChatResponse]] = OrderedDict()

    @staticmethod
    def cacheable(request: ChatRequest) -> bool:
        return request.temperature == 0.0

    def get(self, key: str) -> ChatResponse | None:
        with self._lock:
            hit = self._entries.get(key)
            if hit is None:
                return None
            stored_at, response = hit
            if self._clock.now() - stored_at >= self._config.ttl_s:
                del self._entries[key]
                return None
            self._entries.move_to_end(key)
            return response

    def put(self, key: str, response: ChatResponse) -> None:
        with self._lock:
            self._entries[key] = (self._clock.now(), response)
            self._entries.move_to_end(key)
            while len(self._entries) > self._config.max_entries:
                self._entries.popitem(last=False)

    def __len__(self) -> int:
        with self._lock:
            return len(self._entries)

What to notice. The fingerprint is a SHA-256 over canonical JSON (sort_keys=True, fixed separators), so the same request always hashes the same way. The team is part of the key. Without it, team A could receive an answer generated from team B's prompt. That is a data leak, not a performance detail. The alias is part of the key, but the concrete model is not, because fallback may answer with a different model next time. That is a trade-off worth naming out loud.

Step 11 — Guardrails as a chain

Goal: type the guardrail hook, two real guardrails and the chain that runs them.

Type llm_gateway/guardrails.py:

"""Guardrail hooks, run as a chain on the way in and on the way out.

Each guardrail may pass text through, rewrite it (redaction), or stop the
request with GuardrailViolationError (blocked content). GuardrailChain is
itself a Guardrail, so a chain can nest inside another chain.
"""
import re
from abc import ABC
from collections.abc import Iterable, Mapping
from dataclasses import replace

from .errors import GuardrailViolationError
from .models import ChatRequest, Message

DEFAULT_PII_PATTERNS: Mapping[str, str] = {
    "EMAIL": r"[\w.+-]+@[\w-]+(?:\.[\w-]+)+",
    "CARD": r"\b(?:\d[ -]?){13,16}\b",
    "PHONE": r"\+?\d[\d -]{8,}\d",
}


class Guardrail(ABC):
    """Both hooks default to pass-through; a subclass overrides what it needs."""

    name = "guardrail"

    def check_request(self, request: ChatRequest) -> ChatRequest:
        return request

    def check_response(self, text: str) -> str:
        return text


class PiiRedactionGuardrail(Guardrail):
    name = "pii-redaction"

    def __init__(self, patterns: Mapping[str, str] = DEFAULT_PII_PATTERNS) -> None:
        self._patterns = [(label, re.compile(rx)) for label, rx in patterns.items()]

    def redact(self, text: str) -> str:
        for label, pattern in self._patterns:
            text = pattern.sub(f"[{label}]", text)
        return text

    def check_request(self, request: ChatRequest) -> ChatRequest:
        messages = tuple(Message(m.role, self.redact(m.content)) for m in request.messages)
        return replace(request, system=self.redact(request.system), messages=messages)

    def check_response(self, text: str) -> str:
        return self.redact(text)


class BlockedContentGuardrail(Guardrail):
    name = "blocked-content"

    def __init__(self, blocked_terms: Iterable[str]) -> None:
        terms = [re.escape(t) for t in blocked_terms if t.strip()]
        self._pattern = re.compile("|".join(terms), re.IGNORECASE) if terms else None

    def _check(self, text: str, where: str) -> None:
        if self._pattern is not None and self._pattern.search(text):
            raise GuardrailViolationError(self.name, f"blocked term in {where}")

    def check_request(self, request: ChatRequest) -> ChatRequest:
        self._check(request.prompt_text(), "request")
        return request

    def check_response(self, text: str) -> str:
        self._check(text, "response")
        return text


class GuardrailChain(Guardrail):
    name = "chain"

    def __init__(self, guardrails: Iterable[Guardrail] = ()) -> None:
        self._guardrails = tuple(guardrails)

    def check_request(self, request: ChatRequest) -> ChatRequest:
        for guardrail in self._guardrails:
            request = guardrail.check_request(request)
        return request

    def check_response(self, text: str) -> str:
        for guardrail in self._guardrails:
            text = guardrail.check_response(text)
        return text

What to notice. Guardrail is an ABC whose two hooks default to pass-through. A request-only guardrail overrides one method and inherits the other. The regexes are deliberately simple and live in a mapping you can replace. Real PII detection is a service of its own, and the seam is exactly this class. The pattern order matters too: CARD runs before PHONE, or a card number would be half-eaten by the phone pattern.

Step 13 — The gateway

Goal: type LLMGateway, the pipeline that ties every collaborator together.

Type llm_gateway/gateway.py:

"""The gateway: one front door that every team calls instead of a provider.

complete() runs the pipeline in a fixed order:

  guardrails in -> route -> cache -> quota -> fallback chain
  (each model: breaker + retries) -> settle quota -> ledger
  -> guardrails out -> cache store -> audit

The gateway orchestrates; each step's logic lives in its own collaborator.
Shared state lives only inside those collaborators, each behind its own lock,
so complete() is safe to call from many threads at once.
"""
import logging
import math
import random
import uuid

def _new_request_id() -> str:
    return uuid.uuid4().hex[:12]


class LLMGateway:
    def __init__(
        self,
        providers: Mapping[str, ModelProvider],
        config: GatewayConfig | None = None,
        clock: Clock | None = None,
        router: RoutingStrategy | None = None,
        guardrail: Guardrail | None = None,
        audit: AuditLog | None = None,
        rng: random.Random | None = None,
        id_factory: Callable[[], str] = _new_request_id,
    ) -> None:
        self._config = config or GatewayConfig()
        missing = {s.provider for s in self._config.models.values()} - set(providers)
        if missing:
            raise ValueError(f"no provider registered for {sorted(missing)}")
        self._providers = dict(providers)
        self._clock = clock or SystemClock()
        self._router = router or TableRouter(self._config)
        self._guardrail = guardrail or GuardrailChain()
        self._audit = audit or InMemoryAuditLog()
        self._new_id = id_factory
        self._quotas = QuotaManager(self._config.teams, self._clock, self._config.rate_window_s)
        self._ledger = CostLedger(self._config.models, self._clock)
        self._cache = ResponseCache(self._config.cache, self._clock)
        self._retrier = Retrier(self._config.retry, self._clock, rng or random.Random())
        self._breakers = {key: CircuitBreaker(key, self._config.breaker, self._clock)
                          for key in self._config.models}

    @property
    def ledger(self) -> CostLedger:
        return self._ledger

    @property
    def quotas(self) -> QuotaManager:
        return self._quotas

    def breaker(self, model_key: str) -> CircuitBreaker:
        return self._breakers[model_key]

    # -- the pipeline -----------------------------------------------------

    def complete(self, request: ChatRequest) -> ChatResponse:
        started = self._clock.now()
        policy = self._quotas.policy(request.team)
        audit = AuditRecord(self._new_id(), request.team, route="", outcome="",
                            prompt_chars=len(request.prompt_text()))
        try:
            request = self._guardrail.check_request(request)
        except GuardrailViolationError as err:
            self._finish(audit, started, outcome="blocked_request", error=str(err))
            raise
        decision = self._router.route(request, policy)
        key = fingerprint(request, decision.alias)
        audit = replace(audit, route=decision.alias, prompt_fingerprint=key)

        if self._cache.cacheable(request):
            hit = self._cache.get(key)
            if hit is not None:
                self._finish(audit, started, outcome="cache_hit", cached=True,
                             model_key=f"{hit.provider}/{hit.model}")
                return replace(hit, request_id=audit.request_id, cost_usd=Decimal("0"),
                               cached=True, fallbacks=())

        reservation = self._quotas.reserve(request.team, self._estimate(request))
        try:
            spec, result, failed = self._run_chain(request, decision)
        except GatewayError as err:
            self._quotas.release(reservation)
            self._finish(audit, started, outcome="error", error=type(err).__name__)
            raise
        self._quotas.settle(reservation, result.usage.total)
        entry = self._ledger.record(audit.request_id, request.team, spec.key, result.usage)
        audit = replace(audit, model_key=spec.key, input_tokens=result.usage.input_tokens,
                        output_tokens=result.usage.output_tokens, cost_usd=entry.cost_usd,
                        fallbacks=len(failed))
        try:
            text = self._guardrail.check_response(result.text)
        except GuardrailViolationError as err:
            self._finish(audit, started, outcome="blocked_response", error=str(err))
            raise
        response = ChatResponse(audit.request_id, text, spec.provider, spec.model,
                                result.usage, result.stop_reason, entry.cost_usd,
                                fallbacks=failed)
        if self._cache.cacheable(request):
            self._cache.put(key, response)
        self._finish(audit, started, outcome="ok")
        return response

    # -- helpers ----------------------------------------------------------

    def _estimate(self, request: ChatRequest) -> int:
        """Worst case: every prompt token plus the full max_tokens of output."""
        prompt = math.ceil(len(request.prompt_text()) / self._config.chars_per_token)
        return prompt + request.max_tokens

    def _run_chain(self, request: ChatRequest, decision: RouteDecision
                   ) -> tuple[ModelSpec, ProviderResult, tuple[str, ...]]:
        failures: list[tuple[str, Exception]] = []
        for spec in decision.targets:
            try:
                result = self._call_model(spec, request)
            except CircuitOpenError as err:
                failures.append((spec.key, err))
                continue
            except ProviderError as err:
                if not err.retryable:
                    raise
                log.warning("%s failed (%s); falling back", spec.key, type(err).__name__)
                failures.append((spec.key, err))
                continue
            return spec, result, tuple(key for key, _ in failures)
        raise AllProvidersFailedError(decision.alias, failures)

    def _call_model(self, spec: ModelSpec, request: ChatRequest) -> ProviderResult:
        provider = self._providers[spec.provider]
        breaker = self._breakers[spec.key]
        timeout = self._config.provider_timeout_s
        return self._retrier.run(
            lambda: breaker.call(lambda: provider.complete(spec.model, request, timeout)))

    def _finish(self, audit: AuditRecord, started: float, **changes: object) -> None:
        latency = self._clock.now() - started
        self._audit.write(replace(audit, latency_s=latency, **changes))

What to notice. Read complete() top to bottom. It is the pipeline from the module docstring, one call per step. Three details matter:

  • The quota is reserved after the cache check. A cache hit costs no tokens, so it should not use up the team's limit.
  • If the fallback chain fails, the except releases the reservation before re-raising. Nobody pays for nothing.
  • The ledger records the cost before the output guardrail runs. If the guardrail then blocks the response, the money was still spent, and the ledger says so.

_call_model nests the breaker inside the retrier: retrier.run(lambda: breaker.call(lambda: provider.complete(...))). Read it inside out. That nesting is decision 3 in code.

    def setUp(self):

    def flaky(self, errors, result="ok"):
        queue = list(errors)
        calls = []

        def operation():
            calls.append(1)
            if queue:
                raise queue.pop(0)
            return result
        return operation, calls

    def test_retryable_errors_are_retried(self):
        op, calls = self.flaky([ProviderServerError("500"), ProviderRateLimitError("429")])
        self.assertEqual(self.retrier.run(op), "ok")
        self.assertEqual(len(calls), 3)
        self.assertGreater(self.clock.now(), 0)

    def test_non_retryable_fails_fast(self):
        op, calls = self.flaky([ProviderInvalidRequestError("400")])
        with self.assertRaises(ProviderInvalidRequestError):
            self.retrier.run(op)
        self.assertEqual(len(calls), 1)
        self.assertEqual(self.clock.now(), 0)

    def test_gives_up_after_max_attempts(self):
        op, calls = self.flaky(overloaded(5))
        with self.assertRaises(ProviderOverloadedError):
            self.retrier.run(op)
        self.assertEqual(len(calls), 3)

    def test_retry_after_hint_is_honoured(self):

        self.retrier.run(op)
        self.assertEqual(self.clock.now(), 2.0)

    def test_retry_after_beyond_max_wait_gives_up_at_once(self):

Honest limits. Everything is per process. Two gateway instances would each allow a team its full rate limit, and each would keep its own breakers and cache (see the follow-ups). The token estimate is a character count, not a tokenizer. The ledger lives in memory, and a crash loses it. In production every ledger entry goes to durable storage before the response returns. 9. Common interview follow-ups

"Now we need streaming." What changes? Add a second method to the seam, ModelProvider.stream(...), returning an iterator of text deltas plus a final usage event. The final output-token count arrives only at the end of a stream, so the quota reservation stays open until the stream finishes, and settle runs then. Fallback only works before the first byte. Once a partial answer has reached the caller, switching models mid-sentence would hand them a stitched-together reply. Output guardrails get harder: you either buffer a window of text before releasing it, or accept that a blocked term may be half-sent and cut the stream. The cache stores the assembled response after a clean finish. The pipeline order stays the same, and every collaborator keeps its job.

Why not semantic caching from day one? A semantic cache returns a stored answer for a request that means the same thing, found by embedding similarity. Three costs. First, every lookup needs an embedding call, so even a miss adds latency and money. Second, a near-match is sometimes wrong: "cancel my order" and "don't cancel my order" can sit close in embedding space. A false hit returns a confidently wrong answer, which is worse than a miss. Third, you need a similarity threshold tuned per use case, and an eval set to tune it against. So ship exact-match first, and measure the hit rate. If near-duplicates are common, add a CacheStrategy seam with a semantic implementation, enabled per route for tasks where a near-match is safe, such as FAQ answers.

"Now run three gateway instances behind a load balancer." Rate limits and budgets must move to shared storage. Usually that means Redis, with the check-and-reserve done atomically in one Lua script or a sorted-set window per team. The QuotaManager interface stays; a RedisQuotaManager implements it. Breakers can stay per instance, since each instance learning on its own that a provider is down costs a few failed calls. The cache can move to Redis too, keyed by the same fingerprint. The ledger becomes an append-only table or event stream, written before the response returns.

"Providers now offer prompt caching, with cheaper cache-read tokens." How does billing change? Usage gains fields. Anthropic, for example, reports cache_creation_input_tokens and cache_read_input_tokens beside input_tokens and output_tokens. ModelSpec gains a price for each, and CostLedger.price sums them. Nothing else moves. Note that this is the provider's cache, which saves on a repeated prompt prefix, and it is different from our response cache, which skips the call entirely.

"Route to whichever model is fastest right now." A new RoutingStrategy that orders the chain by each model's recent p95 latency, measured from the audit stream. The gateway doesn't change. Keep the cost-tier filter, though, or "fastest" quietly becomes "most expensive".

"Teams want tool use and structured output." The unified types must grow: Message.content becomes a list of typed blocks (text, tool call, tool result), and ChatRequest carries tool definitions. Each adapter maps blocks to its vendor's format. Fallback gets riskier, because two models may call the same tools differently. Many teams pin tool-heavy routes to a single model family for that reason.

Why does the breaker ignore 400s? Because a 400 says the request was malformed, not that the provider is sick. If a buggy client sent fifty bad requests and opened the circuit, every other team would lose that model. Health signals must come from failures that are the provider's fault.

Why reserve max_tokens up front instead of trusting the caller? Because the output size is unknown until the end, and admitting on a guess lets one team overshoot its tokens-per-minute limit by a wide margin. Reserving the worst case is pessimistic but safe, and settle gives back the difference seconds later. A side effect is a gentle nudge: teams that set max_tokens honestly get more requests through.

Should a request that fell back still be a success? Yes for the caller, but not silently. The response carries fallbacks, and the audit record counts them. A route that falls back on 30% of requests is an incident in disguise, even if every caller saw a 200.
